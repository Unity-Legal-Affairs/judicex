# راه‌اندازی رایگان دستیار وکالت رحیمی روی اندروید (Termux)

این روش برنامه را روی خود گوشی اجرا می‌کند؛ VPS، دامنه و هزینه میزبانی لازم نیست.

## محدودیت‌ها و هشدارها
- برنامه فقط وقتی در دسترس است که Termux و فرایند سرور در گوشی فعال باشند.
- آدرس برنامه فقط روی همان گوشی است: http://127.0.0.1:5051
- این روش به‌تنهایی دستیار هوش مصنوعی مولد محلی فراهم نمی‌کند. امکانات مدیریت پرونده، ثبت اسناد، گردش‌کارها و قالب‌های آماده بدون مدل زبانی قابل استفاده‌اند.
- برای استفاده از مدل زبانی باید بعداً یک ارائه‌دهنده جداگانه تنظیم شود؛ هیچ کلید API یا سند موکل را در مخزن GitHub قرار ندهید.
- نسخه پروژه alpha است. تا انجام بررسی امنیتی، از بارگذاری اسناد واقعی و محرمانه موکلان خودداری کنید. ابتدا با اطلاعات آزمایشی کار کنید.
- Termux ممکن است در اندروید به‌علت مدیریت باتری بسته شود؛ اجرای دائمی تضمین‌شده نیست.

## ۱. نصب Termux
Termux را فقط از منبع رسمی دریافت کنید:
https://github.com/termux/termux-app/releases

یا از F-Droid:
https://f-droid.org/packages/com.termux/

نسخه‌های Termux از منابع مختلف امضای متفاوت دارند؛ برنامه و افزونه‌های آن را از منابع مختلف با هم ترکیب نکنید. نسخه قدیمی Play Store را با نسخه‌های دیگر جایگزین نکنید مگر پس از تهیه نسخه پشتیبان از داده‌های Termux.

## ۲. نصب دستیار
Termux را باز کنید و دستور زیر را عیناً وارد کنید:

```bash
pkg update -y && pkg upgrade -y
pkg install -y git python clang make pkg-config libjpeg-turbo libpng freetype libwebp zlib openssl libffi rust
git clone --branch Iran-legal --single-branch https://github.com/mohamadrezarahimi2000/judicex.git
cd jud icex
```

اگر دستور آخر به‌دلیل فاصله اشتباه کپی شد، دستور صحیح آن این است:

```bash
cd ~/judicex
```

سپس نصب را اجرا کنید:

```bash
bash deploy/android/install.sh
```

## ۳. اجرای برنامه
هر بار برای اجرا:

```bash
cd ~/judicex
bash deploy/android/start.sh
```

برنامه را در Chrome با نشانی زیر باز کنید:

http://127.0.0.1:5051

سرور را با بستن نشست Termux یا فشردن Ctrl+C متوقف می‌کنید.

## ۴. حفاظت از اطلاعات
- ابتدا فقط پرونده و اسناد ساختگی آزمایش کنید.
- رمز ورود محلی قوی و منحصربه‌فرد تنظیم کنید.
- قفل صفحه گوشی را فعال نگه دارید.
- از پایگاه داده نسخه پشتیبان بگیرید و آن را در محل امنی خارج از پوشه پروژه نگهداری کنید.
- پوشه داده‌ها و فایل‌های پرونده را به GitHub ارسال نکنید.
- برنامه را با bind روی 0.0.0.0 یا از طریق تونل عمومی در اینترنت منتشر نکنید.

## ۵. عیب‌یابی
اگر نصب یک بسته با خطای کامپایل مواجه شد، متن کامل خطا را ذخیره کنید و برای بررسی بفرستید؛ دستورهای تصادفی یا فایل APK ناشناس نصب نکنید.

اگر صفحه باز نشد، ابتدا بررسی کنید Termux هنوز در حال اجراست و پیام خطایی در آن نمایش داده نشده باشد.
